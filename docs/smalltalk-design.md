# 🚗 雑談モード(Small Talk Quest)設計書

対象バージョン: v1.18.0〜(3フェーズ) / 作成日: 2026-08-16 / ステータス: **設計のみ・未実装**

## 1. 目的と実際の場面

2026年11月のISSY39と、その翌日のChung-Ang Universityシンポジウム訪問で、**英語の雑談を「続けられる」**ようになるための訓練モード。想定する実場面は4つ:

| 場面 | 相手 | 特徴 |
|---|---|---|
| 🚗 **車中2時間** | Kyoung-Dong Kim(Wistar研究所時代の元同僚、現Chung-Ang University)+同乗するかもしれない他のISSY39参加者 | 学会翌朝、Koreana Hotel(ソウル)→Chung-Ang University(安城)。最長・最重要。沈黙が気まずい閉鎖空間。旧交を温める+初対面が混ざる可能性 |
| 💑 **Claireの紹介** | Kyoung-Dong・他の参加者 | 車中とシンポ訪問に同行するパートナーClaireを自然に紹介し、会話に巻き込む |
| 🍻 **ISSY39懇親会** | 学会参加者(初対面中心) | 立食・短い会話の連続。話題の切り出しと切り上げ |
| 🍽️ **シンポ後のDinner** | Chung-Ang大のホスト陣 | 着席・長め。招待への感謝+落ち着いた話題の持続 |

言語は**主に英語**。ところどころに**韓国語のひとこと**を混ぜて場を温める(수고하셨습니다 など、既習フレーズの実戦投入)。

## 2. 設計方針

「ネタを知っている」「英語でどう言うか知っている」「会話として続けられる」は別のスキルなので、3つの部品に分けて作る。すべて既存エンジンの再利用で実装コストを抑える。

1. **📚 ネタ帳(Topic Deck)** — インプット。話題×英語モデルライン集
2. **🚗 シナリオバトル** — 型の練習。既存の会話トレーニングエンジン(Convo)で4場面を訓練
3. **🤖 AI自由会話** — 実戦練習。AIがKyoung-Dong役になり、自由入力で2時間ドライブを模擬

## 3. 📚 ネタ帳(Phase A)

### 3-1. カード構造

```js
// js/topics.js(新規。index.html+sw.jsへの登録が必要)
{ id: 'kr-food-1', cat: 'korea', icon: '🍜',
  title: 'ソウルで何を食べるべき?',
  opener: "I have one free evening in Seoul — what's the one thing I absolutely have to eat?",
  openerJa: 'ソウルで1晩だけ自由なんです — 絶対食べるべきものを1つ挙げるなら?',
  follow: [
    "Is that something locals actually eat, or is it for tourists?",
    "How spicy are we talking, on a scale from one to crying?"
  ],
  followJa: ['それは地元の人が本当に食べるもの?観光客向け?', '辛さはどのくらい?1〜「泣くレベル」で言うと?'],
  note: '「おすすめを1つだけ」と絞ると相手が真剣に考えてくれて会話が続く。返答には必ずリアクション+追加質問。',
  ko: { t: '맛있겠다!', k: 'マシッケッタ!', ja: 'おいしそう!' }   // 任意: 混ぜる韓国語
}
```

- **opener**(切り出し)+**follow**(深掘り質問2つ)+**note**(なぜ効くか)の3点セットが核。「話題」ではなく「会話の設計図」として書く
- `ko` は任意。既存phrases.jsの学習済みカードを参照できる場合はcardIdで紐付け、⭐マスター済みなら「実戦投入済み」バッジ

### 3-4. UI

- Language Questホームに**3つ目のタブ「🌐 英語」**を追加するのではなく、独立した「🚗 雑談クエスト」画面(ホームの学会攻略appChoiceに3択目「🚗 雑談の準備」を追加。学会モード中はホーム最上部にも浮上)
- ネタ帳はカテゴリタブ+カード一覧。カードは**openerのTTS再生**(en-US)・お気に入り⭐・「今日の3ネタ」ランダム提示
- お気に入りは**「持ちネタリスト」**として1画面に集約 — 当日の朝、車に乗る前にこれだけ見返す使い方を想定

## 4. 🚗 シナリオバトル(Phase B)

既存Convoエンジン(scenarios.js形式)に**雑談シナリオ群**を追加。長さと構造が既存と違う点だけ拡張する。

- **「🚗 ソウルからの2時間」**(10ターンの長編): ホテル前の再会挨拶→Claireの紹介→同乗者(初対面)への自己紹介→Wistarの思い出→窓外の風景から韓国ネタ→**沈黙が訪れる(立て直しターン×2)**→アカデミアネタ→到着前の感謝。途中に「韓国語を混ぜるチャンス」ターン(수고하세요/맛있겠다等、選択肢に既習フレーズ)
- **「🍻 ISSY39懇親会」**(6ターン): 切り出し→深掘り→輪に入る→切り上げ→re-connect
- **「🍽️ シンポ後のDinner」**(8ターン): ホストへの感謝→シンポの感想→食事ネタ→日本紹介→乾杯のひとこと(건배!)→締めの挨拶
- 沈黙ターンの選択肢はネタ帳のopenerから出す(**ネタ帳で覚えた武器をここで使う**構造)
- クリアでネタ帳の関連カードがアンロック、という逆導線も検討

## 5. 🤖 AI自由会話「ドライブシミュレータ」(Phase C)

Q&Aシミュレータ(AI.chat)のエンジンを流用した、本命の実戦練習。

- **ペルソナプロンプト**: AIはKyoung-Dong役。「Wistarで一緒だった韓国人研究者。現在Chung-Ang University。車を運転しながら英語で雑談。ときどき韓国語を教えたがる。実際の運転中らしく、話題は軽く、ときどき窓の外の話をする。**2〜3往復ごとに自然な沈黙(...)を作り、ユーザーが話題を出すのを待つ**」
- ユーザーはテキスト入力(まず文字。音声入力は将来)。**20分/2時間換算の「ドライブ進行バー」**: 一定往復数でソウル→高速→休憩所→安城と背景が進む
- **詰まったときのSOSボタン**: 「🆘 ネタ帳を開く」(openerをタップで引用入力)と「🇯🇵 いまの答え方のヒント」
- 終了時にAIが日本語で講評: 会話が続いた度、良かった返し、次に試すこと
- 同乗者モード(難易度+): AIが「初対面のDr. Park」も同時に演じ、2人を相手にする
- APIコスト: 1セッション20往復で数十円程度。設定のClaude/OpenAIキーをそのまま使用

## 8. 注意点・方針メモ

- **時事ネタの鮮度**: トランプ政権・貿易(ナフサ等)の話は変化が速いので、①実装時にリサーチして「聞き方の型」として書く(意見表明ではなく "How is it looking from the Korean side?" 型)、②Phase Cでは「📰 今日の時事ネタをAIに3つ作らせる」ボタンを設け、当日の鮮度はAIで補う
- **地雷メモをカードに含める**: 政治・兵役・日韓歴史などは「自分から出さない・出されたら聞き役」のガイドをnoteに明記
- **Kyoung-Dongの人物メモ**: シナリオとペルソナの精度のため、覚えている範囲の情報(Wistarで何の研究をしていたか、家族、趣味、呼び方=Kyoung-Dong?KD?)を実装前にヒアリングして反映する
- 車内では**運転中の相手に負荷をかけない話題運び**(Yes/Noで終わらない質問だが、考え込ませない)をnoteの原則にする
