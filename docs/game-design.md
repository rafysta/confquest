# ConfQuest 学会攻略モード(ローグライク)設計書

> **この文書は v1.27.0 時点の実装に合わせて更新されています。**
> 数値はすべてコード上の実値です。変更したら、この文書も一緒に直してください。
> 実装: `js/run.js`(進行・戦闘・イベント) / `js/cards.js`(会話カード) /
> `js/bosses.js`(ボス) / `js/minigames.js`(ミニゲーム) / `js/progress.js`(⭐💎・実績)

Slay the Spire型のマップ進行に、会話バトルを戦闘として組み込むモード。**会話がこのゲームの戦闘**である。

## 世界観

あなたは国際学会に参加する研究者。3日間の学会(= 3マップ)を歩き、人と話し、研究費を集め、
各日の最後に待つボスとの対話を乗り切ればクリア。

## 基本ループ

```
マップ表示 → 分岐を選んで進む → ノードのイベント → マップに戻る → …
　　　　　　→ 🛡️質疑応答 → 👑ボス → 翌日のマップへ(全3日)
```

- 1マップ = **8層**。1層につき1ノードだけ通れるので、**1日8ノード / 1ラン24ノード**
- 線で結ばれたノードにしか進めない(各ノードから次層へ1本、40%でもう1本)
- 進行は `lq_run` に自動保存。1日だけ進めて中断→再開ができる

### 層の構成(`Run.genMap()`)

| 層 | ノード数 | 中身 |
|---|---|---|
| 0 | 3 | 必ず 💬研究者(足がかり) |
| 1〜5 | 2〜4 | 抽選 + 固定配置(下記) |
| 6 | 1 | 必ず 🛡️質疑応答(ボス前の関門) |
| 7 | 1 | 必ず 👑ボス |

**固定配置**: ☕休憩所は層5に必ず1つ(50%で層2〜3にもう1つ)、🛒お店は層2〜5に1軒、
🚶コーヒーブレイクは層2〜5に1回、👥名刺交換は層1〜3に**1ランで1回だけ**。
🎴話題トークは1日2〜3個に調整、⭐エリートは1日1つまで。

**抽選の重み**(層1〜5の残り枠): 💬研究者42% / 🎁お宝20% / ❓ランダム16% / 🎴話題トーク14% / ⭐エリート8%

### 3日間

| Day | 名前 | ボス | ボス報酬 |
|---|---|---|---|
| 1 | Day 1: レセプション | 👑 セッション座長 (Prof. Han) | 💰+50 と 🎤座長の推薦状 |
| 2 | Day 2: 本会議 | 👑 分野の大御所 (Prof. Weiss) | 💰+60 と 🥇大御所の名刺 |
| 3 | Day 3: シンポジウム | 👑 鋭いReviewer (Dr. Sato) | 💰+80 |

## プレイヤーのリソース

| リソース | 初期値 | 意味 |
|---|---|---|
| 🧠 メンタル (HP) | 50/50 | 会話の失敗・気まずさで削られる。0でゲームオーバー |
| 💰 研究費 | 30 | 報酬。お店での売買に使う。ランのスコアでもある |
| 🎒 アイテム | 0個 | ガジェット(パッシブ)/ ドリンク(使い切り)/ レリック / バッドアイテム |

💎ジェムショップで**次のランの開始特典**を買える(開始HP+15 = 25💎、開始💰+50 = 15💎、開始アイテムなど)。

### ダメージと報酬の式

```
被ダメージ = |delta| × 4          (delta は -3〜+3。時間切れは 8 固定)
             × 1.25 (⭐エリート) × 1.5 (👑ボス) × 0.75 (🥇大御所の名刺を所持)
報酬(💰)  = 8 + 3 × 好感の合計
             × 2.5 +20 (⭐エリート) / + ボス報酬 (👑)
             × 2 (🛗エレベーター) × 日次倍率 × 1.25 (👔シャツ) × 1.15 (🎤推薦状)
XP        = 5 + ベスト選択数 × 5 + 15 (⭐) + 25 (👑)
```

- **⚡即答ボーナス**: 好感+2以上の選択肢を制限時間の半分未満で選ぶと好感 +1
- **日次倍率**: 1日1回目 ×1.5 / 2回目 ×1.0 / 3回目以降 ×0.7(1日1ランを推奨する設計)
- 🧿お守りを持っていると、HP0になっても一度だけHP15で復活して消滅する

### 制限時間

`カードのlimitSec(10〜15秒) × 設定の倍率` が基準。設定は じっくり2倍 / **ゆっくり1.5倍(既定)** / 標準1 / ハード0.75。
そこに 🎧翻訳イヤホン ×1.25、😪時差ボケ ×0.8、☕コーヒー ×2、⭐エリート ×0.9、👑ボス ×0.9(Day3はさらに×0.75)が乗る。
「読む速さはアイテムと設定で育てる」という設計。

### ランの終わり方

| 終わり方 | 持ち帰り |
|---|---|
| 🎓 3日完走 | ⭐ 研究費全額 + 100pt + レリックボーナス、💎+5、実績「学会制覇」 |
| 🏳️ 撤退 | ⭐ 研究費の40% |
| 💤 ゲームオーバー | ⭐ 研究費の10% |

失敗しても**獲得XPは全額残る**ので、負けても必ず育つ。

## ノードの種類(全11種)

### 💬 研究者(通常戦闘)
1ターンの短い会話カード(全20枚)。良い返しで💰とXP、悪い返しで🧠ダメージ。
**v1.27.0から、手ごたえと結果が同じ画面に出る**(「次へ」のタップが不要)。

### ⭐ エリート(1日1つまで)
会話トレーニングの4ターンシナリオが相手。ダメージ1.25倍・制限時間0.9倍。
勝つと🏆記念トロフィー(効果なしだが80💰で売れる)。

### 🎁 お宝 — ミニゲーム
| 抽選 | ミニゲーム | 報酬 |
|---|---|---|
| 22% | 🎰 スロット(3リールを自分で止める) | 3つ揃い💰40 / 2つ💰15 / 揃わず💰3 |
| 34% | 🧠 学会豆知識クイズ(18問・4択) | 正解💰20(解説つき) |
| 24% | 🗣️ 語学クイズ(韓国語・広東語) | 正解💰15・🧠+5。Language Questの学習済カードと連動しSRSにも記録 |
| 20% | 🎁 そのまま報酬 | 💰15〜30 か 未所持ガジェット1個 |

### 🎴 話題トーク
手札6枚から3ターン、話題を選んで相手の**機嫌(0〜10、初期5)**を上げるカードバトル。
政治・宗教・給料は**地雷札**(即-3・🧠-8)、うわさ話・愚痴は機嫌7以上でだけ効く**リスク札**。
自分の研究の話は、先に相手の研究を聞いていれば効果が上がる。報酬 = `10 + 機嫌×3`。

### 🚶 コーヒーブレイク(動線パズル) — v1.27.0で大幅改善
**15分**の休憩時間に、5人の中から誰に・どの順で会うか決める。
全員には会えない(合計コストが必ず16分以上になるよう生成)。

- 各人に **会話コスト(分)** と **離席時刻(leaveBy)** があり、
  `elapsed < leaveBy` かつ `elapsed + cost ≤ 15` のときだけ会える
- **「価値」**という共通のものさしで報酬を数値化して表示する(`Stroll.value()`):
  `💰1 = 1 / 🧠1 = 2 / XP10 = 8 / ドリンク1個 = 20`。
  これがあるので 💰30 と「🧠+8」と「XP15」を横並びで比べられる
- 各人の**時間帯を横棒で可視化**(薄い帯 = いる時間、濃い帯 = いま行くと使う時間、縦線 = 現在時刻)
- 会えない理由を区別して表示: **💨 もう帰ってしまった** / **⏰ 残りN分では会話M分に足りない**
- 終了後、**総当たりで求めた最善ルート**(`Stroll.bestRoute()`、5人なので最大326通り)と
  自分の動線を**順番つきで並べて採点**する

| ランク | 条件 | ボーナス |
|---|---|---|
| 🏆 パーフェクト | 最善と同じ価値 | 💰+25 と 実績「完璧な動線」 |
| 😄 上出来 | 80%以上 | 💰+15 |
| 🙂 まずまず | 50%以上 | 💰+5 |
| 😅 もう一歩 | 50%未満 | なし |

さらに「何が足りなかったか」を一言で返す(`Stroll.advice()`)。
早く帰る人の取りこぼし → 「○○は6分で帰ります。先に帰る人から回ると…」、
価値の低い人に時間を使った → 「○○に使った時間を、もっと価値の高い人に回せました」。

**この設計の狙いは「正解が後から必ず分かる」こと。** 遊んだあとに最善手を見られるので、
何度か回すうちに「先に帰る人から」「短い会話で隙間を埋める」というコツが自然に身につく。

### 👥 名刺交換(記憶ゲーム・1ランに1回)
3人の名前・所属・研究テーマを覚える(💰+5)。**数ノート先の☕休憩所で再会**し、4択で名前を思い出す。
正解で💰+40・🧠+8・実績、誤答で🧠-6。学会で本当に困る「名前を忘れる」を再現している。

### 🛡️ 質疑応答ディフェンス(毎日ボスの直前)
飛んでくる質問5問(全15問のプール)を **💬答える / 🔁言い換えて確認する / 📝持ち帰る** で捌く。
質問の性質に合った行動が正解。誤答で🧠-5、時間切れで🧠-8。
全問正解で💰40・🧠+10・実績「鉄壁の質疑応答」。

### 🛒 お店(学会ブース)
ガジェット最大3種 + **60%でレリック1種** + ドリンク4種。売値は買値の60%(🎫クーポンで売買20%有利)。
バッドアイテムはここで売って処分できる。

### ☕ 休憩所
**☕休む**(🧠を最大値の30% = 通常+15回復)か **📖予習する**(好きな能力に+30XP)。
50%で🛍️売店も出ていて、買い物してから休める。

### ❓ ランダムイベント
ルーレット演出(**v1.27.0からタップでスキップ可能**)のあと、5種から等確率:

| イベント | 効果 |
|---|---|
| 🛗 エレベーターで大御所と2人きり | 1ターン勝負・**報酬2倍** |
| ☕ コーヒーをこぼす | 🧠-5。50%で親切な人と話せて💰+10 |
| 📦 落とし物を拾う | 70%でドリンク、**30%でバッドアイテム** |
| 🎟️ 抽選会 | 60%で💰10〜30、40%で☕コーヒー |
| 👋 旧友と再会 | 🧠+10 |

### 👑 ボス(各日の最後)
| Day | ボス | ターン | 特徴 |
|---|---|---|---|
| 1 | セッション座長 Prof. Han | 4 | 丁寧だが観察眼が鋭い |
| 2 | 分野の大御所 Prof. Weiss | 5 | 選択肢が難しい |
| 3 | 鋭いReviewer Dr. Sato | 5 | **制限時間が25%短い** |

全ターンベスト選択で実績「完璧な受け答え」。
**v1.27.0から、Day1・2のボス撃破画面に「一晩明けて🧠+15」まで同居**させ、画面を1枚減らしている。

## テンポの設計(v1.27.0)

1ラン24ノードは「じっくり遊ぶ日」向けの分量なので、
**内容は削らず、待ち時間とタップ数だけを削る**方針を取った。

| 改善 | 効果 |
|---|---|
| 1ターン会話の手ごたえと結果を同じ画面に | 研究者ノードごとに **1タップ削減**(1ラン十数タップ) |
| ボス撃破画面に「一晩明け」を同居 | Day1・2で **画面を1枚ずつ削減** |
| ❓ルーレットをタップでスキップ可能に | 待ち時間 1.7秒 → 0秒(放置しても1.4秒) |
| ⭐👑の入場演出を短縮 | 3.4秒 → 2.6秒(従来どおりタップでスキップ可) |

👑ボスの撃破だけは、余韻のために専用の結果画面を残している。

### まだ手を付けていないテンポ改善案

- **1日を8マス→6マス**に(1ラン24→18)。固定配置も減らして「自分で選んだ感」を増やす
  (現状、層1〜5の5マスのうち3マスは☕🛒🚶で埋まるため、自由に選べるのは実質2マス)
- **ランの長さを選べるように**(⚡ショート=1日 / 🏛️フル=3日)。平日と休日で使い分けられる
- **🛡️質疑応答を5問→3問**、またはDay1=3問・Day3=5問と段階化
- 🍀招待状の所持中、💬研究者ノードに入るたびに出る確認ダイアログをやめる

## セーブ

`lq_run` にラン全体を保存(HP・💰・アイテム・マップ・現在位置・使用済カード・名刺交換の状態)。
各アクションの直後に保存されるため、いつ閉じても続きから再開できる。
ただし**戦闘やミニゲームの最中は保存されない**ので、その途中で閉じるとそのノードの進行は失われる
(ノード自体は訪問済みになる)。

## バランス調整メモ(実機で要確認)

- 1ランの体感時間(24ノード。テンポ改善後にもう一度測る)
- 制限時間の既定1.5倍が適切か(英語力の伸びに合わせて下げていく想定)
- 🚶コーヒーブレイクの「価値」の重み(🧠×2・XP×0.8・アイテム20)が実感と合っているか
- 🛡️質疑応答が毎日5問は多くないか
- ボスの難度カーブ(Day3の時間-25%が厳しすぎないか)
