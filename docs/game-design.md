# ConfQuest 学会攻略モード(ローグライク)設計書

> **この文書は v1.29.0 時点の実装に合わせて更新されています。**
> 数値はすべてコード上の実値です。変更したら、この文書も一緒に直してください。
> 実装: `js/run.js`(進行・戦闘・イベント) / `js/cards.js`(会話カード) /
> `js/bosses.js`(ボス) / `js/minigames.js`(ミニゲーム) / `js/progress.js`(⭐💎・実績)

Slay the Spire型のマップ進行に、会話バトルを戦闘として組み込むモード。**会話がこのゲームの戦闘**である。

## 世界観

あなたは国際学会に参加する研究者。3日間の学会(= 3マップ)を歩き、人と話し、研究費を集め、
各日の最後に待つボスとの対話を乗り切ればクリア。

## 基本ループ

```
マップ表示 → 分岐を選んで進む → マスのイベント → マップに戻る → …
　　　　　　→ 🛡️質疑応答 → 👑ボス → 「終える」or「もう1日続ける」
```

- **1ラン = 1日 = 11層**。1層につき1マスしか通れないので **踏破は11マス**
  (v1.28.0までは3日×8層=24マス。ほぼ半分の長さになった)
- 幅3〜4なので **地図には約33マスが並ぶ**。全部は回れないので、どれを取りに行くかがルート選択の意味になる
- 線で結ばれたマスにしか進めない(**各マスから、対応する位置とその左右へ = 最大3方向**)
- 👑ボスを倒したら **「🎓ここで終える」/「🌅もう1日続ける」** を選ぶ。
  続けると 🧠+15、💰とアイテムは持ち越し、報酬倍率が ×1.3 → ×1.6 と上がり、最大3日まで
- 進行は `lq_run` に自動保存。途中で中断→再開ができる

### 層の構成(`Run.genMap()`)

| 層 | マス数 | 中身 |
|---|---|---|
| 0 | 3 | 必ず 💬研究者(足がかり) |
| 1〜8 | 3〜4 | 抽選 + 置く数で制御(下記) |
| 9 | 1 | 必ず 🛡️質疑応答(ボス前の関門) |
| 10 | 1 | 必ず 👑ボス |

**抽選プール** `RUN_NODE_POOL`:
💬研究者44% / 🎁お宝17% / 🎴話題トーク16% / ❓ランダム15% / ⭐エリート8%
⭐エリートは1ランに1つ、🎴話題トークは3つが上限。上限に達した種類はプールから外れる。

**地図に置く数**(出したい体験は抽選の重みではなく置く数で決める):
🛒お店 **3軒**(序盤・中盤・終盤に1つずつ) / ☕休憩所 **2つ** / 🚶コーヒーブレイク **2つ**

⚠ これらは「その層の選択肢の1つとして置く」だけで、**通ることを強制しません**。
1ランでお店に一度も寄らないことも普通にあり、それがトレードオフになります。

### 選ぶ楽しさをどう作っているか(v1.28.0〜)

この型のゲームは **層の数 = プレイ時間**、**線の本数と選択肢の違い = 選ぶ楽しさ**。
v1.27.0まではここが壊れていて、地図は分かれて見えるのに実質は一本道だった。

**(a) 線は「対応する位置とその左右」へ引く**(`genMap()`)

```js
const c = Math.min(b - 1, Math.round(j * (b - 1) / Math.max(1, a - 1)));
[c - 1, c, c + 1].forEach((t) => { if (t >= 0 && t <= b - 1) edges.push([i, j, t]); });
```

以前は「1本、40%でもう1本」だったため、6割以上の場面で行き先が1つしかなかった。

⚠ **層の幅が変わるところでは線が交差する。** 交差を禁じる引き方(単調な区間割当)も
実装して比べたが、選択の余地がない場面が **25% → 43〜48%** に悪化した
(幅を3固定にすると65%まで戻ってしまう)。交差の回避と分岐の多さは両立しないので、
**交差を許す方を採用**した。代わりに `renderMap()` で
**いま立っているマスから伸びる線だけを水色に光らせて**、どこへ行けるかを読み取りやすくしている。

**(b) 同じ層に同じ種類を並べない**(`pickUnique()`)

層ごとに、まだ使っていない種類の中から重み付きで選ぶ。
**層の幅は必ず抽選プールの種類数以下**に制限する(超えると必ず重複するため)。
置く数の制御をする `place()` も、その種類が既にある層は候補から外す。

**実測(3000ランを実際に歩いた結果)**

| 指標 | v1.27.0 | v1.28.0(8層) | **v1.29.0(11層)** |
|---|---|---|---|
| 1ランで踏むマス | 24 | 24 | **11** |
| 地図に並ぶマス | 20 | 20 | **33** |
| 選択の余地がまったく無い分岐 | 64.7% | 25.0% | **18.2%** |
| 行ける先が全部同じ種類 | 79.9% | 37.5% | **27.3%** |
| 行ける先の種類の平均 | 1.21 | 1.77 | **2.06** |
| 1本の道で取れるマスの組み合わせ | 8.0通り | 25.1通り | **50.0通り** |
| 🛒お店と☕休憩所を両取りできる | 58.9% | 87.5% | **100%** |

残った18.2%(= 2/11)は🛡️質疑応答と👑ボスへ進む2マスぶん、
27.3%(= 3/11)はそれに層0(3マスとも💬研究者)を足したぶんで、**すべて構造上のもの**。
**つまり自由に選べる場面では、必ず2〜3個の違う種類から選べる。**

層0が3マスとも💬研究者なのは「最初は必ず会話から」という設計。
種類は同じでも、どこから登るかで層1以降の到達範囲が変わるので選択自体には意味がある。

### 3人のボス

| ボス | ターン | 特徴 | 報酬 |
|---|---|---|---|
| 👑 セッション座長 Prof. Han | 4 | 丁寧だが観察眼が鋭い | 💰+55 💎+2 |
| 👑 分野の大御所 Prof. Weiss | 5 | 選択肢が難しい | 💰+65 💎+2 |
| 👑 鋭いReviewer Dr. Sato | 5 | **制限時間が25%短い** | 💰+80 💎+3 |

1ランで戦えるのは基本1体なので、**まだ倒していないボスが優先で出る**(`Run.pickBoss()`)。
撃破の記録は `lq_boss_beaten`(ランをまたいで残る)。3人すべて倒すと実績「学会の顔」。
全員倒したあとは完全ランダムになり、「今日は誰が来るか」が周回の楽しみになる。

## プレイヤーのリソース

| リソース | 初期値 | 意味 |
|---|---|---|
| 🧠 メンタル (HP) | 50/50 | 会話の失敗・気まずさで削られる。0でゲームオーバー |
| 💰 研究費 | 30 | 報酬。お店での売買に使う。ランのスコアでもある |
| 🎒 アイテム | 0個 | ガジェット(パッシブ)/ ドリンク(使い切り)/ レリック / バッドアイテム |

💎ジェムショップで**次のランの開始特典**を買える(開始HP+15 = 25💎、開始💰+50 = 15💎、開始アイテムなど)。

### ダメージと報酬の式

```
被ダメージ = |delta| × 4          (delta は -3〜+3。時間切れは 8 固定)
             × 1.25 (⭐エリート) × 1.5 (👑ボス) × 0.75 (🥇大御所の名刺を所持)
報酬(💰)  = 8 + 3 × 好感の合計
             × 2.5 +20 (⭐エリート) / + ボス報酬 (👑)
             × 2 (🛗エレベーター) × 日次倍率 × 1.25 (👔シャツ) × 1.15 (🎤推薦状)
XP        = 5 + ベスト選択数 × 5 + 15 (⭐) + 25 (👑)
```

- **⚡即答ボーナス**: 好感+2以上の選択肢を制限時間の半分未満で選ぶと好感 +1
- **日次倍率**: 1日1回目 ×1.5 / 2回目 ×1.0 / 3回目以降 ×0.7(1日1ランを推奨する設計)
- 🧿お守りを持っていると、HP0になっても一度だけHP15で復活して消滅する

### 制限時間

`カードのlimitSec(10〜15秒) × 設定の倍率` が基準。設定は じっくり2倍 / **ゆっくり1.5倍(既定)** / 標準1 / ハード0.75。
そこに 🎧翻訳イヤホン ×1.25、😪時差ボケ ×0.8、☕コーヒー ×2、⭐エリート ×0.9、👑ボス ×0.9(Day3はさらに×0.75)が乗る。
「読む速さはアイテムと設定で育てる」という設計。

### ランの終わり方

| 終わり方 | 持ち帰り |
|---|---|
| 🎓 ボスを倒して終える | ⭐ 研究費全額 + **60pt × 続けた日数** + レリックボーナス、💎 **2 + 日数** |
| 🏳️ 撤退 | ⭐ 研究費の40% |
| 💤 ゲームオーバー | ⭐ 研究費の10% |

1日で終えれば ⭐+60・💎3、3日続ければ ⭐+180・💎5。
日次倍率(1日1回目×1.5 / 2回目×1.0 / 3回目以降×0.7)はそのまま効くので、**1日1〜2ラン**が基本。

失敗しても**獲得XPは全額残る**ので、負けても必ず育つ。

## マスの種類(全10種)

### 💬 研究者(通常戦闘 + 時々クイズ)
1ターンの短い会話カード(全20枚)。良い返しで💰とXP、悪い返しで🧠ダメージ。
手ごたえと結果が同じ画面に出る(「次へ」のタップが不要)。

**v1.29.0から、20%で🧠学会の豆知識クイズ、12%で🗣️語学クイズになる。**
「宝箱を開けたらクイズ」より「隣の人と学会の豆知識で盛り上がる」ほうが自然なため、
🎁お宝から移してきた。導入文(`TRIVIA_INTRO` / `LANG_INTRO`)で会話の流れに馴染ませている。

### ⭐ エリート(1日1つまで)
会話トレーニングの4ターンシナリオが相手。ダメージ1.25倍・制限時間0.9倍。
勝つと🏆記念トロフィー(効果なしだが80💰で売れる)。

### 🎁 お宝
| 抽選 | 中身 | 報酬 |
|---|---|---|
| 35% | 🎰 スロット(3リールを自分で止める) | 3つ揃い💰40 / 2つ💰15 / 揃わず💰3 |
| 65% | 🎁 そのまま報酬 | 💰15〜30 か 未所持ガジェット1個 |

クイズは v1.29.0 で💬研究者マスへ移動した。

### 🎴 話題トーク
手札6枚から3ターン、話題を選んで相手の**機嫌(0〜10、初期5)**を上げるカードバトル。
報酬 = `10 + 機嫌×3`。

**v1.29.0で「何を基準に選ぶか」を全部見えるようにした**(`Topic.cardGuide()`)。
以前はルールが隠れていて、プロフィール(🔍ヒント)以外に手がかりが無かった。

| 印 | 意味 | 例 |
|---|---|---|
| 🟢 安全 | いつ出しても外さない。⭐が多いほど盛り上がる(⭐⭐=基礎点+2) | 🍜食べ物 ✈️旅 🧬相手の研究(⭐⭐) / 🌤️天気 ⚽スポーツ(⭐) |
| 🟡 条件つき | 条件を満たすまではマイナス。**いまの状況での可否をカードに書く** | 🗣️うわさ話・😮‍💨愚痴(機嫌7以上で効く) / 📊自分の研究(先に🧬相手の研究を聞く) |
| 🔴 地雷 | 出すと機嫌-3・🧠-8 | 🗳️政治 ⛪宗教 💴給料 |

そのうえで、**相手の好みに合えば さらに +1、嫌いなら -1**。好みは🔍ヒントから読む。
カードの左端の色と、青字の一言(「打ち解けてから(機嫌7以上で効く・いま5)」など)で
判断材料がすべて画面に出るので、あとは**出す順番**を考えるゲームになる。

### 🚶 コーヒーブレイク(動線パズル) — v1.27.0で大幅改善
**15分**の休憩時間に、5人の中から誰に・どの順で会うか決める。
全員には会えない(合計コストが必ず16分以上になるよう生成)。

- 各人に **会話コスト(分)** と **離席時刻(leaveBy)** があり、
  `elapsed < leaveBy` かつ `elapsed + cost ≤ 15` のときだけ会える
- **「価値」**という共通のものさしで報酬を数値化して表示する(`Stroll.value()`):
  `💰1 = 1 / 🧠1 = 2 / XP10 = 8 / ドリンク1個 = 20`。
  これがあるので 💰30 と「🧠+8」と「XP15」を横並びで比べられる
- 各人の**時間帯を横棒で可視化**(薄い帯 = いる時間、濃い帯 = いま行くと使う時間、縦線 = 現在時刻)
- 会えない理由を区別して表示: **💨 もう帰ってしまった** / **⏰ 残りN分では会話M分に足りない**
- 終了後、**総当たりで求めた最善ルート**(`Stroll.bestRoute()`、5人なので最大326通り)と
  自分の動線を**順番つきで並べて採点**する

| ランク | 条件 | ボーナス |
|---|---|---|
| 🏆 パーフェクト | 最善と同じ価値 | 💰+25 と 実績「完璧な動線」 |
| 😄 上出来 | 80%以上 | 💰+15 |
| 🙂 まずまず | 50%以上 | 💰+5 |
| 😅 もう一歩 | 50%未満 | なし |

さらに「何が足りなかったか」を一言で返す(`Stroll.advice()`)。
早く帰る人の取りこぼし → 「○○は6分で帰ります。先に帰る人から回ると…」、
価値の低い人に時間を使った → 「○○に使った時間を、もっと価値の高い人に回せました」。

**この設計の狙いは「正解が後から必ず分かる」こと。** 遊んだあとに最善手を見られるので、
何度か回すうちに「先に帰る人から」「短い会話で隙間を埋める」というコツが自然に身につく。

### 👥 名刺交換(記憶ゲーム・1ランに1回) — マスではなくイベント

**v1.29.0でマスを廃止し、ランダムに割り込むイベントにした。** 覚える相手も3人→**1人**。
3人は一度に覚えるには多すぎて、記憶ゲームとして成立していなかった。

- どのマスに入るときも **30%** で直前に発生する(`Run.maybeBadgeMeet()`)
- 🛡️質疑応答と👑ボスの直前には割り込まない
- 終盤(残り4層)まで起きなければ**必ず発生**する(1ランに1回は必ず体験できる)
- 一度起きたら二度と起きない
- 覚えたあとは、割り込む前に入ろうとしていたマスへそのまま進む(`Run.resolveNode()`)

1人の名前・所属・研究テーマを覚える(💰+5)。**少し先の☕休憩所で再会**し、4択で名前を思い出す。
正解で💰+40・🧠+8・実績、誤答で🧠-6。学会で本当に困る「名前を忘れる」を再現している。

### 🛡️ 質疑応答ディフェンス(ボスの直前)
飛んでくる質問5問(全15問のプール)を **💬答える / 🔁言い換えて確認する / 📝持ち帰る** で捌く。
質問の性質に合った行動が正解。誤答で🧠-5、時間切れで🧠-8。
全問正解で💰40・🧠+10・実績「鉄壁の質疑応答」。

### 🛒 お店(学会ブース)
ガジェット最大3種 + **60%でレリック1種** + ドリンク4種。売値は買値の60%(🎫クーポンで売買20%有利)。
バッドアイテムはここで売って処分できる。

### ☕ 休憩所
**☕休む**(🧠を最大値の30% = 通常+15回復)。50%で🛍️売店も出ていて、買い物してから休める。

v1.29.0で「📖予習する(+30XP)」を廃止した。回復と比べてメリットが感じられず、選ぶ理由が無かったため。

### ❓ ランダムイベント

| イベント | 効果 |
|---|---|
| 🛗 エレベーターで大御所と2人きり | 1ターン勝負・**報酬2倍** |
| ☕ コーヒーをこぼす | 🧠-5。50%で親切な人と話せて💰+10 |
| 📦 落とし物を拾う | 70%でドリンク、**30%でバッドアイテム** |
| 🎟️ 抽選会 | 60%で💰10〜30、40%で☕コーヒー |
| 👋 旧友と再会 | 🧠+10 |

### 👑 ボス(1ランの最後)

## テンポの設計(v1.27.0)

1ラン24ノードは「じっくり遊ぶ日」向けの分量なので、
**内容は削らず、待ち時間とタップ数だけを削る**方針を取った。

## 画面構成

```
screen-run-map    : マップ(縦スクロール、ノードをタップで進む)
screen-run-battle : 会話バトル(選択肢UI + HUD + 手ごたえ + 結果)
screen-run-event  : お宝 / お店 / 休憩所 / ランダム / 話題トーク /
                    コーヒーブレイク / 質疑応答 / 名刺交換
screen-run-result : 完走・ゲームオーバー・撤退
```

## セーブ

`lq_run` にラン全体を保存(HP・💰・アイテム・マップ・現在位置・使用済カード・名刺交換の状態)。
各アクションの直後に保存されるため、いつ閉じても続きから再開できる。
ただし**戦闘やミニゲームの最中は保存されない**ので、その途中で閉じるとそのノードの進行は失われる
(ノード自体は訪問済みになる)。
