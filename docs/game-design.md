# ConfQuest 学会攻略モード(ローグライク)設計書

Slay the Spire型のマップ進行に、会話バトルを戦闘として組み込むモード。仮称「**Conference Run**」。

## 世界観

あなたは国際学会に参加する研究者。3日間の学会(= 3マップ)を歩き、人と話し、研究費を集め、最終日のボスとの対話を乗り切ればクリア。**会話がこのゲームの戦闘**である。

## 基本ループ

```
マップ表示 → 分岐を選んで進む → ノードのイベント → マップに戻る → … → ボス → 次の日(マップ)へ
```

- 1つのラン = 3マップ(Day 1〜3)。各マップは縦8層、各層2〜4ノードの分岐グラフ。線で結ばれたノードにしか進めない(Slay the Spire方式)
- Day 1「ポスターセッションとレセプション」/ Day 2「本会議」/ Day 3「シンポジウム」
- 後半の日ほど会話の難度・報酬が上がる

## プレイヤーのリソース

| リソース | 初期値 | 意味 |
|---|---|---|
| 🧠 メンタル (HP) | 50/50 | 会話の失敗・気まずさで削られる。0でゲームオーバー |
| 💰 研究費 (pt) | 30 | 報酬。お店での売買に使う。ランのスコアでもある |
| 🎒 アイテム | 0個 | パッシブ効果の「ガジェット」と使い切りの「ドリンク」 |

既存のステータス(Networking等)のXPはラン中の会話でも獲得でき、恒常的に成長する(ラン失敗でも無駄にならない)。

## ノードの種類

### 💬 研究者(通常戦闘)
他の研究者・同僚・学会参加者との会話バトル。2〜3ターンの短い会話。

- 良い選択 → 好感度上昇。会話終了時の好感度に応じて研究費(10〜30pt)
- 悪い選択 → **HPダメージ**(delta -1→-4HP、-2→-8HP、-3→-12HP)
- 時間切れ → -8HP
- 好感度が一定以上で終わるとXPボーナス

### 🎁 お宝
ミニゲームに挑戦して報酬(研究費 / HP回復 / アイテム)を得る。

1. **スロット**: 絵柄を3つ揃える。止めるタイミングは自分で押す
2. **豆知識クイズ**: 学会・研究者文化の豆知識(例: ポスター賞の慣習、乾杯のマナー)
3. **語学クイズ**: 韓国語・広東語の基礎フレーズ4択(将来のLanguage Questと共有)
4. たまに挑戦なしでそのまま報酬(「机の上に無料のUSBメモリがあった」)

### 🛒 お店(学会ブース)
- アイテム購入・売却(売値は買値の60%)
- HP回復ドリンクも販売
- 「学会クーポン」所持で売買20%有利

### ☕ 休憩所
どちらか選択:
- **休む**: HP 30%回復
- **予習する**: 好きなステータスに+30XP

### ❓ ランダムイベント
ルーレット風の演出の後、イベント画面へ。例:

| イベント | 効果 |
|---|---|
| エレベーターで大御所と2人きり | 1ターンだけの高難度会話。成功で大きな報酬 |
| コーヒーをこぼした | -5HP、ただし「親切な参加者」と会話が始まることも |
| 落とし物を拾う | アイテム入手。**たまにバッドアイテム**(時差ボケ等) |
| 抽選会 | 研究費 or ドリンクが当たる |
| 旧友と再会 | HP回復+次の会話の報酬アップ |

### 👑 ボス(各マップの最後)
- Day 1: **セッション座長** — 4ターン、あなたの発表への質問攻め
- Day 2: **分野の大御所教授** — 5ターン、選択肢が難しい
- Day 3: **鋭いReviewer** — 5ターン、制限時間が短い(-25%)
- 撃破で研究費50pt+**特別アイテム**確定

## スピードゲージとアイテム

制限時間はゲージで表示。**基準時間は設定の倍率(じっくり〜ハード)を反映**し、その上にアイテム効果が乗る。「読む速さはアイテムで育てる」という手応えと、現実の英語力向上の両方が反映される設計。

## アイテム一覧(初期セット)

### ガジェット(パッシブ、持っている間ずっと有効)
| アイテム | 効果 |
|---|---|
| 👔 アイロンがけしたシャツ | 会話の獲得研究費 +25% |
| 🎧 翻訳イヤホン | スピードゲージの減りが25%遅い |
| 💼 名刺入れ | 会話開始時、30%の確率で最悪の選択肢が1つ消える |
| 🏆 記念トロフィー | 効果なし。ただし高く売れる(80pt) |
| 🎫 学会クーポン | お店の売買が20%有利 |
| 🧿 お守り | HP0になっても一度だけHP15で復活し、消滅する |

### バッドアイテム(拾ってしまうことがある)
| アイテム | 効果 |
|---|---|
| 😪 時差ボケ | スピードゲージの減りが25%速い |
| 📚 分厚いプロシーディングス | 会話開始時、30%の確率で紛らわしい選択肢が1つ増える |

バッドアイテムはお店で売って処分できる(安値)。「悪いものを金に変える」楽しさを残す。

### ドリンク(使い切り、会話前に使用)
| アイテム | 効果 |
|---|---|
| ☕ コーヒー | 次の会話だけゲージの減りが半分 |
| 🧃 栄養ドリンク | HP 15回復 |
| 🍀 招待状 | 研究者ノードを1回スキップして通過 |

## バランス初期値(調整前提)

- 1マップ = ノード踏破数 約8(うち研究者3〜4、ボス1)
- 研究者会話の平均報酬 15pt、ボス50pt。お店のガジェット相場 40〜80pt
- 普通にプレイして1ラン15〜25分。1日1マップだけ進めて中断→再開も可(進行を自動保存)
- ゲームオーバーでも獲得XPと研究費の10%は持ち帰り(「毎日やると必ず育つ」を維持)

## 会話コンテンツの供給

ランで最も消費されるのは会話シナリオ。既存の4本(4ターン)はエリート・ボス用に回し、通常戦闘用に**1〜2ターンの短い会話カードを20〜30枚**新規作成する(雑談の入り方、相槌、褒め方、頼み方、断り方など1テーマ1カード)。カードはプールからランダムに引かれるため、周回しても新鮮さが保たれる。

## 画面構成

```
screen-run-map    : マップ(縦スクロール、ノードをタップで進む)
screen-run-battle : 会話バトル(既存の選択肢UI + HPバー + アイテム欄)
screen-run-event  : お宝/お店/休憩所/ランダム
screen-run-result : クリア/ゲームオーバー(スコア、持ち帰りXP)
```

## 実装フェーズ案

1. **Phase 1(コア)**: マップ生成と進行、研究者ノード(既存エンジン改造+HP/研究費)、休憩所、お店とアイテム6種、セーブ
2. **Phase 2(遊び)**: お宝ミニゲーム3種、ランダムイベント、バッドアイテム、ドリンク
3. **Phase 3(仕上げ)**: ボス3体と3日構成、クリア画面、特別アイテム、語学クイズ連携

各フェーズごとに動く状態でリリースし、遊んだ感想でバランス調整する。
